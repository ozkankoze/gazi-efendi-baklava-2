# Gazi Efendi Baklava — Versiyon 2 (Modern Patisserie)

Alemdağ Gazi Efendi Baklava için ikinci tasarım alternatifi: aydınlık, minimalist, ürün odaklı.
Dört bölüm: Hero, Lezzetlerimiz, Hakkımızda (ustalık), İletişim.
Tek sayfalık statik site (`index.html` + `img/`), Vercel'de derleme adımı olmadan yayınlanır.

Birinci versiyon: https://github.com/ozkankoze/gazi-efendi-baklava
